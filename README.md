# Проект test-z02
   

Описание:

    - Проект на базе Laravel 11, с использованием Inertia.js и другими зависимостями.
    - Он включает базовую конфигурацию для аутентификации (Laravel Sanctum), а также инструменты для разработки (Laravel Sail, Pint, PHPUnit).

## Требования
 - PHP версии 8.2 или выше
 - Composer для управления зависимостями PHP
 - Node.js (рекомендуется последняя LTS-версия) и npm (или Yarn/PNPM) для управления фронтенд-зависимостями
 - Расширения PHP, необходимые для работы Laravel (например, OpenSSL, PDO, Mbstring и др.)

## Установка и запуск
#### Установка 
    make install 
#### Запуск
    make run

    
## GUI
    Фреймфорк Vue 3 
    inertiajs Client-side
